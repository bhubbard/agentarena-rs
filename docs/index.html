CRATE ARCHITECTURE // AGENTARENA-CORE

Four Physical & Systems Simulation Domains

MODULE 01 // TRAFFIC.RS

Traffic Grid Simulation

Models arterial road networks with North-South and East-West signal phases, stochastic vehicle arrivals, green-phase saturation flow discharge, and queue buffer gridlock thresholds ($\ge 25$ vehicles).

Actions: switch_heaviest, switch_phase_all, hold_phase
MODULE 02 // TACTICAL.RS

Tactical Squad Combat

Simulates 4v4 fireteam engagements across a 20x10 coordinate grid with cover damage mitigation ($50\%$ reduction), ammunition consumption, pinning suppression fire, and flanking accuracy multipliers.

Actions: advance_to_cover, suppress_fire, flank_enemy, tactical_retreat
MODULE 03 // CROWD.RS

Crowd Evacuation RVO

Evaluates emergency pedestrian egress from high-density venues. Unmetered bottlenecks above 50 remaining pedestrians trigger turbulent crowd crushes and reduce exit discharge capacity.

Actions: deploy_staggered_barriers, open_auxiliary_exit, meter_main_corridor
MODULE 04 // ORCHESTRATOR.RS

Software Team DAG

Models a multi-agent engineering team (Architect, Implementer, Reviewer) executing a 6-module feature backlog while balancing LLM token expenditure ($3/\text{M tokens}$) against code review regressions.

Actions: dispatch_task, run_automated_tests, conduct_code_review
